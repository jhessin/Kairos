# Words of Power

## Early game

אוֹר (OR) - Light, lightning, lights, dawn
חֹשֶׁךְ (ha-she-kh) - darkness, shadow, secret, obscurity
קָּדַשׁ (kah-dash) - Holy, appoint bid, consecrate, dedicate, defile, hallow

| Strong's  | Hebrew  | Transliteration | Meaning                |
| --------- | ------- | --------------- | ---------------------- |
| **H2822** | חֹשֶׁךְ | _ḥōshekh_       | darkness, obscurity    |
| **H6942** | קָדַשׁ  | _qāḏaš_         | sanctify, consecrate   |
|           |         |                 | make/set apart as holy |
